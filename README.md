# LEGION (가제) — 2D 액션 RPG 프로토타입

Phaser 3 + Vite. 외부 에셋 없이 실행되며, 그래픽은 `BootScene`에서 생성한 임시 텍스처입니다.

## 실행 및 배포
```bash
# 1. 로컬 파이썬 SQLite 백엔드 DB 서버 실행 (포트 8000)
python server.py

# 2. 로컬 클라이언트 개발 서버 실행 (포트 5173)
npm run dev      # http://localhost:5173
npm run build    # 배포 빌드 (dist/)

# 3. 버셀(Vercel) 배포
# vercel.json과 api/index.py, requirements.txt가 구성되어 있어 GitHub 연동 후 바로 배포 가능합니다.
vercel
```

## 회원가입 & 로그인 (Python SQLite DB 연동)
- **회원가입 항목**: **아이디, 비밀번호, 이름, 닉네임**
- **데이터 자동 저장**: 게임 내 **레벨, 경험치, HP, MP, 전직 차수(1/2/3차), 몬스터 처치 수, 퀘스트 진행도**가 SQLite(`legion.db`)에 안전하게 저장됩니다.
- **수동 저장**: 상단 `[💾 DB 저장]` 버튼을 누르면 언제든 즉시 서버 DB에 동기화됩니다.
- **게스트 시작**: 비회원으로 로그인 없이 바로 테스트 플레이도 가능합니다.

## 조작 및 차수(전직) 시스템
- **전직 조건**:
  - **1차 (시노비)**: Lv. 1 ~ 29 (기본 시작)
  - **2차 (듀얼시노비)**: **Lv. 30 달성 시 자동 전직**
  - **3차 (풍마거검사)**: **Lv. 60 달성 시 자동 전직**
  - *(테스트용 즉시 전직 전환: `1`키, `2`키, `3`키로 자유롭게 변경 가능)*
- **1차 (시노비)**:
  - **기본 공격 (`Ctrl`)**: 표창만 투척 가능, **최대 2명 이하 타격** (쿠나이 사용 불가)
- **2차 (듀얼시노비)**:
  - **기본 스킬 (`Ctrl`)**: 쿠나이와 표창 사용 가능 (`C`키로 무기 교체), **최대 3명 이하 타격**
  - **몬스터 꽂힘 및 회수 (`Z`)**: 타격된 무기가 몬스터 몸에 꽂히며, `Z`키를 누르면 꽂힌 무기를 뽑아내며 강력한 추가 회수 데미지를 입히고 회수
  - **2차 스킬 추가 (`A`)**: **쿨타임 10초**, 표창과 쿠나이에 **바람 속성**을 부여하여 **4명의 몬스터를 연속 섬멸** (풍둔 이펙트 및 관통 타격)
- **3차 (풍마거검사)**:
  - **3차 공격 (`Ctrl` / `S`)**: **거대 쿠나이와 대형 풍마표창**을 전개하여 사방을 초토화하는 강력한 범위 공격
- **이동 및 공통 조작**:
  - `←` / `→`: 이동 · `X`: 점프 · `Shift` (홀드) + 방향키: 공중 무기 염동력 동시 궤적 조종
  - `↑`: 포탈 이용 · `Z`: 몬스터에 꽂힌 표창 및 공중 무기 전탄 회수
  - `Space`: 마을 NPC와 대화 / 퀘스트 진행

## 맵 & 퀘스트
- **시작 마을 (map01)**: 평화로운 마을 (몬스터 없음). **마을 NPC [장로 타키]**가 위치해 있습니다.
  - **[퀘스트 1] 초록 숲 정화**: 장로 타키에게 대화하여 수락 → 첫 번째 사냥터인 **[초록 숲](map02)의 몬스터 30마리 처치** → 장로 타키에게 복귀하여 완료 보상(350 EXP 및 체력/마나 회복) 획득
- **사냥터 4개 (몬스터 서식 맵)**:
  - map02 초록 숲 (퀘스트 1 대상 사냥터) ↔ map03 버섯 군락지 ↔ map04 잊힌 유적 ↔ map05 망령의 숲
- 맵 이동 시 레벨·경험치·HP·MP·처치 수·차수·퀘스트 상태 유지

## 구조
- `src/config/gameConfig.js` — HP, 공격력, 속도, 공격 간격, 경험치 등 모든 수치
- `src/config/maps.js` — 맵 ID·이름·배경 테마·크기·발판·몬스터 배치·포탈(연결 맵/도착 X)
- `src/entities/` — Player(이동/상태), Monster(AI/HP), Projectile(표창 이동)
- `src/systems/` — CombatSystem(충돌·피해·타격 효과), ExperienceSystem(경험치/레벨, 최대 120), MapManager(지형 생성·포탈·맵 전환·상태 유지)
- `src/ui/HUD.js` — 레벨, HP/MP, 경험치 바, 현재 맵 이름, 처치 수, 조작 안내
- `src/scenes/` — BootScene(임시 텍스처 생성), GameScene(맵 데이터로 재시작되는 공용 플레이 씬)

## 에셋 교체
`BootScene`의 텍스처 키(`player`, `monster`, `shuriken`, `spark`, `ground`)를 유지한 채 이미지 로드로 바꾸면 됩니다. 히트박스는 각 엔티티의 `body.setSize/setOffset`에서 조정합니다.

## 확장 지점
직업: Player 상속 또는 공격 전략 분리 · 보스: Monster 상속 · 퀘스트: `monster-killed` 이벤트 구독 · 새 맵: `maps.js`에 항목 추가 후 기존 맵 포탈의 `to`에 연결
